## How to Add to VSCode
1. Clone this repo
2. Install Node.js and PNPM
3. Run `pnpm build`
4. Download a fresh official VS Code archive and unpack it
5. Copy the `dist` folder that was generated by the build system into `<vscode path>/resources/app/extensions` (and ideally give it a more suitable name)
6. That VS Code installation will now have AI banished!
