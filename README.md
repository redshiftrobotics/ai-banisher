# VS Code AI Banisher

A simple extension for VS Code that disables all built-in AI features, prevents users from re-enabling them, directly blocks the installation of many popular AI extensions, and uninstalls any extensions that appear AI-related.  

The extension can be installed as a "built-in" extension into a VS Code installation, which prevents it from being visible in the UI or being disabled.  

This extension is designed to be used in conjunction with WPILib VS Code, but will work in any installation.

## Repository Structure
The `extension` folder contains the actual VS Code extension itself, which is written and TypeScript and expects to be built using `pnpm`.  
Use `pnpm package` to compile the extension and prepare it for installation.  

The `installer` folder contains a lightweight C# program that downloads the packed extension from a VS Code release and installs it on WPILib VS Code.

## Installation on WPILib
1. Acquire the installer (either build from source with the .NET SDK or download the installer from the Releases tab)
2. Install WPILib (currently, the installer targets version `2027_alpha7`
3. Run the installer
4. That WPILib VS Code instance will now have AI banished!

## Installation on Any VS Code
1. Clone this repo
2. Install Node.js and PNPM
3. Go to the `extension` directory
4. Run `pnpm package`
5. Download a fresh official VS Code archive and unpack it
6. Copy the `dist` folder that was generated by the build system into `<vscode path>/resources/app/extensions` (and ideally give it a more suitable name)
7. That VS Code installation will now have AI banished!
